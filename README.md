# 🏛️ Aref-Oriental (G2G Digital Services Platform)

A secure institutional and administrative web application built with **Laravel**, designed to facilitate Government-to-Government (G2G) digital services, data exchange, and inter-departmental workflows for the Oriental region.

---

## 🚀 Core Features

* **Inter-Agency Data Exchange:** Secure channels for sharing documents, reports, and administrative requests between government entities.
* **Role-Based Access Control (RBAC):** Strict authentication hierarchies for regional directors, department heads, system administrators, and partner agencies.
* **Audit Logging & Security:** Comprehensive tracking of all system requests, record updates, and data transfers to maintain high compliance standards.
* **Automated Institutional Workflows:** Streamlined submission, review, and approval cycles for public sector operations.

---

## 🛠️ Tech Stack

This platform relies on modern, enterprise-grade open-source tools:


### Backend
| Technology | Purpose | Version Requirement |
| :--- | :--- | :--- |
| **PHP** | Core Server-Side Language | `^8.3` or `^8.4` |
| **Laravel Framework** | Application Architecture | `^11.0` / `^13.0` |
| **MySQL / MariaDB** | Relational Database Management | `v8.0+` / `v10.4+` |
| **Composer** | PHP Package Manager | `^2.6+` |

### Frontend
| Technology | Purpose | Version Requirement |
| :--- | :--- | :--- |
| **Node.js & NPM** | JavaScript Runtime & Manager | `^20.0+` (LTS) |
| **Vite** | Frontend Asset Bundler | `^5.0+` |
| **Blade / Tailwind CSS** | UI Layouts & Styling | Latest |

* **Database:** MySQL
